# NOA: AFTER BELL

A mobile-first psychological horror prototype set in a school after midnight.

## Play

Best experienced on a phone in landscape orientation.

- Left thumb: move
- Right-side swipe: look
- 🔦: flashlight
- NOA: in-game phone
- Desktop fallback: WASD / mouse drag / F / P

## Prototype

The current build is intentionally small: a dark school corridor, a brightly lit gym, one supernatural encounter, and an exit.

No build step or external dependencies are required. The game is plain HTML/CSS/JavaScript and can be deployed directly as a static site.
